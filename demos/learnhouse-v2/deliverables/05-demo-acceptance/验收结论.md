# V2 本地 Demo 接口验收结论

2026 年 11 月 20 日在隔离环境完成真实 HTTP 验收，**主流程 139 项、专项 74 项、最终定向回归 21 项全部通过，0 项失败**。139/74 项在前一轮业务实现后运行；随后新增父策略门禁、任务 ETag 对齐和审计枚举修正，最终重启后 21 项只针对父策略门禁与任务 ETag 回归，没有重跑全部检查。审计枚举修正已加载，但本轮没有新增证据正文接口的对应 HTTP 分支验证。

验收使用实际 LearnHouse 账号密码获取会话 Cookie，通过 V2 接口写入真实 PostgreSQL 数据；没有使用权限绕过测试夹具。三组检查包含回归重叠，不代表 234 个互不重复的功能，也不代表最后版本的全量回归证明。

## 已验证的成果

1. 五个演示账号可以真实登录，学生、教师与平台管理员的会话角色由服务器计算。两门课程、两个班级相互隔离；管理员仅能读取管理元数据，不能读取教学正文。
2. 老课程和活动 API 入口在 Demo 模式下拒绝访问；匿名请求、缺失/外来 Origin、伪造角色请求头均不能绕过身份与范围检查。
3. 教师可以新建真实作业并布置给当前班级；学生可以创建私人草稿、保存并提交。重复请求返回同一结果，同键不同内容、陈旧版本和提交后覆盖被拒绝。
4. 混合题进入教师评分流程。教师评价显式生效后形成成绩版本；两个独立教师会话同时改分，仅一个成功，另一个得到版本冲突。旧成绩、替代关系与原始答卷得到保留。
5. 学生可以发起成绩复核，教师处理复核。改分触发新的统计画像版本，页面数据明确标注为规则统计，不冒充认知画像模型结果。
6. 固定布尔表达式模板经过生成、服务端校验、教师审核、发布、布置、学生作答和规则判分，完成完整链路。当前策略要求人工审核时，规则模板也不能跳过审核。生成与判分均明确标记演示来源。
7. 笔记默认私人可见；学生明确授权后，本班指定教师才可查看。教师阅读许可不会自动产生画像用途授权，撤回立即生效，跨班教师和管理员仍不可读。
8. 未配置的研究生成、AI 评分返回明确不可用状态，不执行模型调用。当前 Demo 不执行学生代码。
9. 管理员可以按课程/班级对其他账号授权、撤权、停用、启用和撤销会话，但不能向自己授权教学权限或停用自己。撤权后旧 Cookie 和曾经成功的写命令幂等重放都不能继续访问；重新启用账号也不会恢复旧会话。
10. 来源必须属于当前课程并匹配内容哈希；客观题答案必须有正确的类型或选项。策略按原家族追加版本，课程不能放宽全局预算或审核要求；业务执行会检查当前策略，不能引用旧版本绕过被关闭的生成模式。专项结束后所有临时授权、停用和限制均已恢复。
11. 全局策略更新后，尚未对齐父版本的课程不能发起新内容写入；两门课通过追加策略完成对齐后可继续操作。管理后台任务列表和详情使用一致的执行版本标识，任务详情不暴露结果正文引用。

## 已处理的问题与当前边界

联调发现上游初始化后的角色序列未推进，已在隔离种子脚本中校准；部分 PostgreSQL 空参数需要显式类型转换，已修复后通过全套接口验收。初始策略字段已在种子脚本中规范；已有数据库通过管理员 API 在原全局/课程家族追加标准版本，旧作业仍冻结原版，未重写历史。Demo 启动过程已关闭上游 RAG、邮件、字幕和回填后台任务，避免演示数据触发非预期外部服务。

本结论覆盖已列出的本地业务链路与权限检查。浏览器页面、截图与操作体验由项目总体验收另行记录。生产部署、压力测试、灾难恢复、短信登录和研究模型效果不在本轮完成范围；本轮结果不能作为认知双身、序列画像、推荐或教学质量算法已实现的证明。
